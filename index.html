每一层都能追踪，每一次扩展都有位置

Nullus 把创作工具、运行时和底层系统放进同一条主线。你可以从 Editor 开始，也可以直接深入渲染、资产或脚本边界。

01 / MAINLINE CONNECTED

同一套运行时，贯穿 Editor 到 Player

场景、资产和脚本在 Editor 中编辑，在 Game 中运行，再由 Build Profile 进入桌面 Player。内容不需要换一套表达方式。

02 / RENDERING FRAME READY

显式 RHI，把性能路径摊开给你看

Game Thread、Render Thread 与 RHI Submit 各自负责明确的一段工作，FrameGraph 管理 pass、资源状态和依赖。

03 / CONTENT ARTIFACTS
